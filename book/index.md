# 固定收益证券：理论、模型与中国市场实践

面向中国高年级本科生（可本研贯通）的固定收益证券教材。

本书把**理论推导**、**Python/QuantLib 实现**与**中国债券市场真实数据案例**三位一体，
每章配**学习目标**与**习题/编程实验**，所有代码均可在配套 notebook 中运行——
默认依赖内置离线数据，也可一键在 Colab/Binder 云端打开。

## 如何使用本书

- **在线阅读**：左侧导航按六个部分组织，共 18 章 + 5 附录。
- **运行代码**：每章顶部有 Colab 与 Binder 徽章，点开即可云端运行该章 notebook。
- **本地环境**：见 [附录A 本地环境配置](appendix/a-setup.md)，`uv sync` 一键装好。
- **数据**：优先使用内置离线样本，联网案例用免费的 akshare/tushare（见 [附录C](appendix/c-data-sources.md)）。
