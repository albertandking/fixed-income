# 固定收益证券：理论、模型与中国市场实践

本教材面向金融学、金融工程、经济学及相关专业的高年级本科生，也适合作为研究生入门课程和固定收益从业者的自学资料。

全书围绕"**理解原理—掌握模型—完成计算—解释市场**"展开，将固定收益证券的理论推导、Python/QuantLib 实现与中国债券市场案例结合起来，帮助读者建立从现金流定价到组合管理、从利率风险到信用风险的完整知识体系。

> **教材特色**  
> 理论与实践并重，公式与代码互证；既讲清经典固定收益模型，也关注中国市场的交易制度、数据口径与实际应用。

---

## 本书主要内容

学习本教材后，读者将能够：

- 理解债券、货币市场工具及利率衍生品的基本结构与现金流特征；
- 掌握债券定价、收益率计算和利率期限结构构建方法；
- 运用久期、凸性等指标识别和管理利率风险；
- 分析浮息债、含权债、可转债及结构化产品的定价逻辑；
- 理解信用利差、违约风险与信用风险度量的基本框架；
- 使用 Python 和 QuantLib 完成定价、风险计量、策略回测与结果解释；
- 将理论模型应用于中国债券市场数据和真实业务情境。

| 第三部分：风险度量与组合 | 如何衡量利率变化对价格和组合的影响？ | 第 6 章 久期与凸性；第 7 章 组合管理 |

## 推荐学习路径

### 路径一：系统学习

适合首次学习固定收益证券的读者。建议按照第 1 章至第 18 章的顺序阅读，先建立定价与收益率基础，再进入风险管理、衍生品和信用产品。

### 路径二：定价与风险

适合已经掌握金融学基础、希望强化量化分析的读者。建议重点学习第 2–7 章，并进一步阅读第 11–14 章。

### 路径三：中国市场实践

适合关注债券投资、交易和风险管理实务的读者。建议在掌握第 3–7 章后，重点学习第 16–18 章，并同步完成各章的数据案例和编程实验。

## 如何使用本书

- **在线阅读**：左侧导航按六个部分组织，共 18 章和 5 个附录。
- **运行代码**：每章顶部设有 Colab 和 Binder 徽章，点击即可在云端运行该章 notebook。
- **本地环境**：参见[附录 A：本地环境配置](appendix/a-setup.md)，使用 `uv sync` 安装项目环境。
- **数据使用**：优先使用教材内置的离线样本；联网案例使用免费的 akshare 或 tushare 数据，详见[附录 C：中国债券市场数据源](appendix/c-data-sources.md)。

### 学习建议

1. **先看学习目标**：明确每章需要理解的概念、掌握的方法和能够完成的计算。
2. **跟随正文推导**：关注模型假设、公式含义及其适用边界，而不只是记忆结论。
3. **运行配套代码**：建议修改示例参数，观察价格和风险指标随之发生的变化。
4. **完成习题与实验**：通过计算题巩固基本方法，通过编程实验连接模型与市场数据。
5. **回到市场解释结果**：尝试用交易制度、收益率曲线和风险暴露解释模型输出。

## 先修知识

开始学习前，建议具备以下基础：

- 微积分基础；
- 线性代数基础；
- 概率论与数理统计基础；
- 金融学基本概念；
- Python 基础语法和简单的数据处理能力。

如果暂时不熟悉 Python，可以先阅读理论部分，再按照附录中的环境配置说明运行示例代码。编程是理解模型和检验结论的工具，不是开始学习本书的门槛。
