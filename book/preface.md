# 前言

固定收益市场是中国金融体系的"压舱石"：国债收益率曲线是全社会资产定价的基准，
货币政策经由债券市场向实体经济传导（MLF、LPR、公开市场操作）。
理解债券如何定价、利率风险如何度量与管理，是金融、经济、金融工程专业学生的核心能力。

现有固定收益教材，或重理论而轻实现，或重实务而缺原理，且大多缺乏面向教学的
"可运行代码 + 真实中国数据 + 习题实验"一体化设计。本书希望弥补这一缺口。

## 本书特色

1. **理论—模型—中国市场案例三位一体**：每个概念都落到中国债市的真实品种与数据上。
2. **可运行**：每段公式都配可运行的 Jupyter Notebook，默认依赖内置离线数据，断网也能跑；
   每章顶部提供 Colab 与 Binder 徽章，一键云端运行。
3. **可复现**：依赖用 `uv` 管理、`uv.lock` 锁定版本；数据优先使用免费的 akshare/tushare，
   Wind 等付费终端仅作"如有授权可选"。
4. **重训练**：每章配学习目标、概念题、计算题与编程实验。

## 读者对象与先修知识

本书面向金融、经济、金融工程等专业的高年级本科生，也可用于研究生入门。
先修知识：微积分、概率统计、线性代数基础，以及 Python 编程基础。
