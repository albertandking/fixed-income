# 前言

固定收益市场是现代金融体系的重要基础。政府通过发行债券筹集公共建设资金，金融机构借助固定收益工具开展流动性管理，企业通过债券融资优化资本结构，投资者则利用债券及其衍生品进行资产配置和风险管理。与此同时，国债收益率曲线构成金融资产定价的重要基准，债券市场也是中央银行货币政策向金融市场和实体经济传导的关键渠道。因此，理解固定收益证券的定价逻辑、收益特征与风险管理方法，是金融学、金融工程、投资学等专业人才应当具备的基本能力。

固定收益证券看似具有相对明确的现金流结构，其定价与风险分析却涉及货币时间价值、利率期限结构、久期与凸性、信用风险、嵌入期权和结构化融资等一系列重要理论。随着金融市场的发展，固定收益产品的类型日益丰富，定价模型和交易策略日趋复杂，传统上以概念讲解和公式推导为主的教学方式，已经难以完全满足人才培养和市场实践的需要。特别是在金融科技快速发展的背景下，如何将理论模型转化为可以计算、检验和应用的分析工具，已经成为固定收益证券教学必须回应的问题。

目前，国内外固定收益证券教材各有侧重：部分教材具有严密的理论体系，但对模型实现和中国市场制度关注不足；部分教材突出市场实务，却缺少对定价原理和数量方法的系统阐释；还有一些教材虽然介绍了计算工具，但理论、数据、代码与实际业务之间尚未形成完整联系。基于此，我们编写了《固定收益证券：理论、模型与中国市场实践》，力求在理论严谨性、市场现实性和计算可操作性之间取得平衡，引导读者从"理解固定收益"逐步走向"分析固定收益"和"应用固定收益"。

本书以固定收益证券的现金流分析为起点，以定价、收益和风险为主线，按照由基础到进阶、由单一证券到组合管理、由理论分析到综合应用的逻辑展开。全书共分为六个部分。

第一部分为"基础与工具"，主要介绍固定收益证券的基本特征、中国债券市场的组织结构和主要品种，并讲解计息惯例、现金流计算与货币时间价值，为后续学习建立统一的概念和计算基础。

第二部分为"定价与收益率"，系统阐述债券定价原理、不同收益率指标及其经济含义，并进一步介绍即期利率、远期利率和利率期限结构，以及收益率曲线的构建方法。这一部分是理解固定收益产品价值形成机制的核心。

第三部分为"风险度量与组合"，重点讨论久期、修正久期和凸性等利率风险指标，在此基础上介绍债券组合管理、免疫策略和风险敞口控制方法，帮助读者建立从单只债券分析到投资组合管理的完整思维。

第四部分为"利率衍生品和高级品种"，涵盖浮动利率债券、可赎回债券、可回售债券、可转换债券，以及利率期货、远期、互换和期权等内容。这一部分着重揭示复杂现金流、嵌入期权与利率风险之间的关系，帮助读者掌握固定收益创新产品的定价和风险管理方法。

第五部分为"信用与结构化产品"，主要介绍信用风险的识别、度量与定价，并讨论资产证券化产品的现金流重组、分层结构和风险特征，以拓展读者对信用债券和结构化融资的认识。

第六部分为"市场机制和综合应用"，从货币市场工具与回购市场出发，进一步介绍债券投资策略、量化回测与固定收益风险管理系统，推动读者将前述理论、模型和方法运用于较为完整的投资分析与风险管理场景。

为方便不同基础的读者学习，本书还设置了本地计算环境配置、开源定价库 QuantLib 速查、中国债券市场数据源、数学与公式推导、术语与符号表等附录，形成由理论知识、计算方法、市场数据到实践应用相互支撑的内容体系。

本书在编写过程中重点体现以下几个方面的特色。

第一，立足中国债券市场。书中在介绍固定收益基本理论的同时，注重结合我国银行间债券市场、交易所债券市场、政策利率体系、国债收益率曲线、信用债券、回购交易和资产证券化等制度与产品，引导读者理解固定收益理论在中国市场环境中的具体表现与应用边界。

第二，贯通理论、模型与实践。对于债券价格、收益率、期限结构、利率风险和信用风险等核心内容，本书既说明其经济逻辑，也进行必要的公式推导，并通过市场案例展示模型的实际用途，避免将理论学习、数量分析与市场实践相互割裂。

第三，强化计算与实证训练。本书将 Python 和 QuantLib 等计算工具引入教学，通过可运行的程序、数据案例和编程实验，将抽象公式转化为可以观察、检验和复现的计算过程。读者不仅能够理解模型"是什么"和"为什么"，还能够掌握模型"如何实现"和"如何应用"。

第四，突出能力导向。各章设置学习目标、重点概念、计算分析、案例讨论、习题和编程实验，注重培养读者识别问题、构建模型、处理数据、解释结果和管理风险的综合能力。书中的计算工具不是理论学习的替代，而是帮助读者深化理论认识、连接市场实践的重要手段。

本书主要面向金融学、金融工程、投资学、经济学及相关专业的高年级本科生，也可作为研究生固定收益证券、债券投资与金融工程等课程的入门教材。对于从事债券投资、资产管理、风险管理、金融科技和相关研究工作的读者，本书亦可作为学习和实践参考。读者如具备微积分、线性代数、概率统计和 Python 编程的基本知识，将更有利于理解书中的数量模型和计算案例；不具备编程基础的读者，也可以先掌握各章的经济逻辑和基本方法，再循序渐进地完成计算实验。

固定收益证券连接着宏观经济政策、金融市场运行和微观投资决策。学习固定收益，不仅是学习一套债券定价公式，更是学习如何理解利率、信用、流动性和风险在时间维度上的配置与交换。我们希望本书能够帮助读者建立完整的固定收益知识体系，形成以现金流为基础、以市场价格为信号、以风险管理为约束的分析框架，并进一步提升运用现代计算工具解决中国债券市场实际问题的能力。

本书在编写过程中参考和吸收了固定收益证券领域的经典理论、研究成果和市场实践，也得到了有关专家、同行和学生的帮助与支持，在此一并表示诚挚感谢。由于固定收益市场制度不断完善、金融产品持续创新，加之编者水平有限，书中难免存在疏漏和不足，恳请广大读者和同行专家批评指正，以便在今后的修订中不断完善。读者如发现书中或配套代码中的问题，欢迎通过本书 GitHub 仓库提交 Issue 指正。
